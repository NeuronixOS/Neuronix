# After install

Checklist for finishing this setup. Edit or delete items as you go.

- [ ] Sign in to cloud accounts (browser, email, etc.)
- [ ] Review `~/configs` and commit any machine-specific tweaks
- [ ] Confirm web roots under `/var/www` (also `~/www`) if you host sites
- [ ] Install secrets under `~/configs/secrets/` (tokens, keys) if needed
- [ ] Verify crontab (`crontab -l`) if you ship `configs/crontab/`
