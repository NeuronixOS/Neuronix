# personalize/configs/gtk-apps/gtk-files/

Override file-manager settings from `default/configs/gtk-apps/gtk-files/`.

## Example `config.toml` (snippet)

```toml
[general]
show_hidden = false
default_view = "list"
```

## Example `places.toml` (snippet)

```toml
[[places]]
name = "Projects"
path = "~/Projects"

[[places]]
name = "SORT"
path = "~/SORT"
```
