# configs/notes/

Post-install setup notes. Files here (except README / `.gitkeep` / `*.example`)
are **copied** to `~/Notes` on the live/installed user home (`links.json`
`type: copy`).

Use this for checklists of what to finish after first boot (API keys, DNS,
cloud sync, etc.). Edit the copies under `~/Notes` freely; change the source
tree here to update future installs.
