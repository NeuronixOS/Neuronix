# personalize/gtk-apps/gtk-theme/

Optional overlay of `/usr/share/neuronix/gtk-theme/` (shared theme assets used by
the suite). Same-named files replace `default/gtk-apps/gtk-theme/` copies.

## Example layout

```text
gtk-theme/
  python/          # Python helpers imported by themed apps
  *.css / assets   # whatever the suite expects under gtk-theme/
```
